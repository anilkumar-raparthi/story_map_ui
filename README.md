# Butterfly Life Cycle — Interactive React App


## Run locally


1. Copy files into a folder
2. `npm install`
3. `npm run dev`


The app uses Vite + React + Framer Motion for smooth animations. All artwork is included as SVGs in `src/assets/`.


## Notes
- Accessible: stage icons are buttons with keyboard focus; popups close on ESC and outside click.
- Responsive: icons resize with CSS and media queries.
- Data-driven: edit `src/data/stages.json` to reposition or change stages.
